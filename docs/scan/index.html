Scan an APK in your browser

Free static check of the app's manifest. Your APK never leaves this page (no upload, no server).

Want proof, not just a list?

  • Full scan on GitHub Actions: fork the repo, open Actions → ProofDroid scan → Run workflow, paste an https:// link to the APK, then download the report with screenshots and logs.
  • Run locally: proofdroid scan app.apk (see the README).

Only scan apps you own or are authorised to test.
